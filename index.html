적용 시 참고사항

  • 배너 한 장에 버튼이 2개라, 이미지 위에 투명 클릭 영역(<a>)을 % 단위로 얹는 방식입니다. 배너 크기를 줄이거나 늘려도 클릭 영역이 자동으로 맞습니다. 배너 크기는 max-width 값만 바꿔주세요.
  • 팝업·배너 관리 기능이 “이미지 1장 + 링크 1개”만 지원하는 경우, 코드 대신 이미지만 등록하면 버튼 하나만 연결됩니다. 이때는 HTML(코드) 입력 방식으로 등록하거나, 이미지맵을 사용하도록 요청하세요.
  • 팝업의 닫기 버튼·“오늘 하루 보지 않기”는 홈페이지 쪽 팝업 기능을 그대로 사용하면 됩니다.
  • 이미지는 현재 이 GitHub Pages에서 제공됩니다. 업체 서버에 이미지를 직접 올려 쓰는 경우, 코드의 <img src="..."> 주소만 바꾸면 됩니다.

이메일 배너 (가로형)

email-banner.html을 열고 배너를 전체 선택(Ctrl+A) → 복사(Ctrl+C) → 메일 본문에 붙여넣기(Ctrl+V) 하세요. HTML 편집이 되는 발송 툴이라면 소스의 <table> 부분을 붙여넣으면 됩니다.

※ Mac 사용 시: 전체 선택(⌘A) → 복사(⌘C) → 붙여넣기(⌘V)
